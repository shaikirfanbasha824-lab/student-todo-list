# Student To-Do List

A beginner-friendly student project built with **HTML, CSS, and JavaScript**.

## Features

- Add tasks using the button or Enter key
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- See total and completed task counts
- Automatically save tasks in browser `localStorage`
- Responsive layout for mobile and desktop
- No frameworks or installation required

## Run the project

1. Download and extract this ZIP file.
2. Open the `student-todo-list` folder.
3. Double-click `index.html` to open it in your browser.

## Project files

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — task actions and browser storage

## GitHub

Create a repository named `student-todo-list`, then upload these four files to it.

## Learning goals

This project demonstrates DOM manipulation, event listeners, arrays and objects, JSON, browser local storage, and responsive CSS.
